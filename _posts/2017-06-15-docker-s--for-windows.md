<p>There are at least two ways to use Docker in Windows. Some major differences we have to be careful before diving in.</p><h3 id="docker-is-not-a-vm">Docker is not a VM</h3><p>The most important concept to know is that Docker is not a VM. Linux programs won’t magically runs within Windows when we use Docker.</p><p>Simple rules to remember:</p><ul><li>Windows Containers runs only in Windows.</li><li>Linux Container runs only in Linux.</li></ul><h3 id="1st-method-docker-toolbox">1st method: Docker Toolbox</h3><p>This what happened when we go to official Docker website follow the download link for <a href="https://www.docker.com/products/docker-toolbox">Docker Toolbox</a></p><p>In essence there will be a Linux VM running within Windows all times. All docker commands typed in the command line are just routed to a docker daemon running within this Linux VM.</p><p>Most docker images in the official registry are created for Linux and will be able to run with this method.</p><p>The setup used to be pretty complicated but this becomes much easier since Hyper-V is now part of Windows 10 so there’s no need to download additional VirtualBox or other VM Host software.</p><p><strong>Important Points</strong></p><ul><li>Hyper-V is only available in Windows 10 Professional.</li><li>MobyVM running in Hyper-V has limited RAM assigned to it. Watch out for containers that may eat up all those precious RAM.</li><li>Law of Physics dictates: More RAM to VM = Less RAM to Windows. Take that to account as well.</li></ul><figure class="kg-card kg-image-card"><img src="/assets/images/ghost/downloaded_images/Docker-s--for-Windows/1-I_jBNUMmuuIm_ACfAjSaTA.png" class="kg-image" alt loading="lazy"></figure><h3 id="2nd-method-microsoft-windows-container">2nd method: Microsoft Windows Container</h3><p>This is Microsoft’s own container technology, aptly named <a href="https://docs.microsoft.com/en-us/virtualization/windowscontainers/about/">Microsoft Windows Container</a> which becomes available starting from Windows 10 Anniversary Edition and Windows Server 2016.</p><p>Considered this approach “native” docker for Windows. All docker commands talks directly to this Windows Container subsystem.</p><p>Most containers in registry will not work here because they were made as linux containers. Notable exception is of course <a href="https://hub.docker.com/u/microsoft/">Microsoft official Docker Repos</a> except for SQL Server for Linux and a few things</p><p>The starting point for this method is not very obvious and Googling “Docker for Windows” will mostly yield documentations from the first method. Luckily the complicated multi-step setup has been revamped to a simple few steps in <a href="https://docs.microsoft.com/en-us/virtualization/windowscontainers/quick-start/quick-start-windows-10">Windows Containers on Windows 10</a> link.</p><p><strong>Important Points</strong></p><ul><li>Windows Container is only available in Windows 10 Professional.</li><li>Read the Prerequisites carefully</li><li>If you are using Parallels, this is how to turn on Nested Virtualization Support <a href="http://kb.parallels.com/en/116239">http://kb.parallels.com/en/116239</a></li></ul>
