loading="lazy"></figure><p>เดี๋ยวนี้เริ่มเล่นเครื่องมือ ML ต่างๆ ตัว Python Environment มีหลาย dependency ตีกันมั่วไปหมด แล้วก็แชร์โค้ดให้เพื่อนลองเล่นยากต้องเขียนวิธีลง package ต่างๆ ไว้ใน README.md</p><p>มาลองใช้ Conda กันดูว่าจะช่วยได้ยังไง</p><h3 id="install">Install</h3><p>เนื่องจากเราเป็นสาวก ลงอะไรก็ง่าย แต่รอโหลดนานหน่อย</p><pre><code>brew cask install anaconda</code></pre><p>เสร็จแล้วใส่บรรทัดนี้ไว้ใน .bash_profile หรือ .zshrc</p><pre><code>export PATH=/usr/local/anaconda3/bin:"$PATH"</code></pre><h3 id="create-environment">Create Environment</h3><p>หลังจากนั้นเราก็สร้าง Environment ขึ้นมาใช้ได้ตามใจชอบ ซึ่งจะต่างกับใช้ virtualenv ตรงที่ environment พวกนี้จะสร้างไว้รวมกันที่เดียวไม่รก environment ที่ใช้</p><p>สมมติว่าเราจะสร้าง environment ไว้สำหรับลองเล่น Keras (ตั้งชื่อว่า keras)โดยใช้ python 3.7 ก็พิมพ์ตามนี้</p><pre><code>conda create -n keras python=3.7</code></pre><figure class="kg-card kg-image-card"><img src="/assets/images/ghost/downloaded_images/-----------------Machine-Learning------Conda/1-bl0rXLdISPeV63zhxv34ow.png" class="kg-image" alt loading="lazy"></figure><h3 id="activate-deactivate-environment">Activate/Deactivate Environment</h3><p>สร้างเสร็จก็ switch เข้าไปที่ environment นั้นได้เลย</p><pre><code>source activate keras</code></pre><p>ถ้าจะออกมาก็ใช้</p><pre><code>source deactivate</code></pre><p>สังเกตว่าตอนที่เรา switch เข้าไป ตัว prompt จะมีชื่อ environment ในวงเล็บนำหน้า</p><figure class="kg-card kg-image-card"><img src="/assets/images/ghost/downloaded_images/-----------------Machine-Learning------Conda/1-Ci7oPdiRPYRAxaMZ5KAjgQ.png" class="kg-image" alt loading="lazy"></figure><h3 id="install-packages">Install Packages</h3><p>ตอนนี้ได้แต่ environement เปล่าๆ ยังไม่มีประโยชน์ ลองลง package ที่ต้องใช้ดู</p><pre><code>conda install keras jupyterlab</code></pre><p>หลังจากเราลงไปแล้วก็เปิด jupyter lab แล้วใช้ keras ได้ทันที</p><figure class="kg-card kg-image-card"><img src="/assets/images/ghost/downloaded_images/-----------------Machine-Learning------Conda/1-t4y3_WBqGLJQOusE3yltrQ.png" class="kg-image" alt loading="lazy"></figure><h3 id="share-environment">Share Environment</h3><p>ของเด็ดอยู่ตรงนี้ คือ เราสามารถบอก spec ของ environment เราลงไฟล์ที่จะโยนงานไปให้เพื่อนทำต่อได้</p><pre><code>conda env export &gt; environment.yml</code></pre><p>จากนั้นก็ checkin ไฟล์ environment.yml เข้าไปพร้อมกับโปรเจค</p><p>ถึงเวลาอีกฝั่งหนึ่ง clone git เสร็จแล้ว ก็สร้าง environment ได้เหมือนกันแบบนี้</p><pre><code>conda env create -f environment.yml</code></pre><h3 id="reference">Reference</h3><ul><li><a href="https://conda.io/docs/user-guide/tasks/manage-environments.html">https://conda.io/docs/user-guide/tasks/manage-environments.html</a></li></ul>
