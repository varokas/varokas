จะซื้อก๋วยเตี๋ยวได้แค่ 2 ชาม แทนที่จะเป็น 4 ชามในปัจจุบัน</p><p>จำนวนเงินในตุ่มไม่ว่าตอนไหนก็ 200 บาทไม่หายไปไหน แต่ซื้อก๋วยเตี๋ยวได้น้อยชามลง เพราะราคาก๋วยเตี๋ยวเพิ่มขึ้น</p><h3 id="future-value">Future Value</h3><p>คือ การคำนวนว่า ราคาก๋วยเตี๋ยวเมื่อผ่านไปแต่ละปี จะมีมูลค่าเท่าไหร่ ซึ่งจะแพงขึ้นกว่าราคาเดิมไปเรื่อยๆ</p><p>เมื่อเรารู้ว่า อัตราเงินเฟ้อคือ 2.1% ทุกปี ก็จะคำนวณได้ทีละปีแบบนี้</p><ul><li>ปีที่ 1 = 50 x (1+0.021) = 51.05</li><li>ปีที่ 2 = 51.05 x (1+0.021) = 52.12</li><li>ปีที่ 3 = 52.12 x (1+0.021) = 53.22</li><li>…</li><li>ปีที่ 34 = 99.27 x (1+0.021)=101.36</li></ul><p>ถ้าค่อยๆ ทำแบบนี้ ทุกปีๆ มันเหนื่อย ก็เลยออกมาเป็นสูตรสำเร็จเลย แบบนี้</p><p>FV = PV x (1.0121)^n</p><p>สำหรับ Future Value ของเงิน 50 บาท ในปีที่ 34 ก็จะเป็น</p><p>FV = 50 x 1.021^34 = 50 x 2.027 = 101.36</p><h3 id="--3">ทำไปทำไม?</h3><p>สมมติว่าเราใช้เงินเดือนละ 40,000 บาทพอแล้ว</p><p>อีก 34 ปีข้างหน้า จะต้องมีเงินเดือนละ 40,000 x (1.021)^34 =81,084
