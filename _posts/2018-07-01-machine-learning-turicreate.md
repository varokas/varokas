<h3 id="-">ทำได้เองง่ายๆวันนี้บนเครื่องตัวเองตั้งแต่ต้นจนจบ</h3><p>สาวกหลายๆคนเห็นวิดีโอสาธิต <a href="https://developer.apple.com/documentation/create_ml">CreateML</a> ของ macOS 10.14 ที่เอารูปดอกไม้มาโยนใส่ใน directory ย่อยๆ แล้วสร้าง Machine Learning โมเดลไปใช้เองได้ทันที ก็คงอยากจะลองไปทำบ้าง</p><p>ตามดูได้จาก 1:00:08 เป็นต้นไป ที่นี่ <a href="https://developer.apple.com/videos/play/wwdc2018/102/">https://developer.apple.com/videos/play/wwdc2018/102/</a></p><figure class="kg-card kg-image-card kg-card-hascaption"><img src="/assets/images/ghost/downloaded_images/Machine-Learning-----------/1-mhtO2fo15i57nQF21wW07g.jpeg" class="kg-image" alt loading="lazy"><figcaption>มันเป็นปาฎิหารย์!!</figcaption></figure><p>ติดอยู่ที่สาวกหลายคนอาจจะยังศรัทธาไม่พอจะเอา macOS mojave beta มาลงที่เครื่องตัวเองตอนนี้ แต่อาจจะยังไม่รู้ว่า จริงๆแล้วสามารถบันดาลสิ่งเหล่านี้ได้เลยวันนี้</p><p>มาลองทำ Machine Learning แยกรูปกันเองดู​ (ง่ายมาก)​ เริ่มกันตั้งแต่มีรูป ไปจนถึงใช้บน iOS ได้เลย</p><h3 id="turicreate">TuriCreate</h3><p>อันนี้เป็น opensource ที่ Apple ปล่อยออกมาตั้งแต่ปลายปีที่แล้ว ชื่อว่า <a href="https://github.com/apple/turicreate">turicreate</a> มีพลังอภินิหารย์ในการสร้างโมเดลคล้ายกับ CreateML มาก เพียงแต่ต้องเอาไปรันใน python แทนที่จะเป็น swift</p><p>วิธีลงก็ตามที่อยู่ในหน้าเวป <a href="https://github.com/apple/turicreate">https://github.com/apple/turicreate</a> แต่หลักๆคือ ตามนี้</p><pre><code>brew install python3
