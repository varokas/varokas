<p>Managing dependencies in Python is kind of a mess. Let's try to make that better with <code>pipenv</code></p><h2 id="install">Install</h2><h3 id="macos">MacOS</h3><pre><code class="language-bash">brew install pipenv</code></pre><h3 id="windows">Windows </h3><p>First, install any version of Python 3 from the offical Python website. <a href="https://www.python.org/downloads/windows/">https://www.python.org/downloads/windows/</a></p><p><strong>** Do not use the version that installed via Microsoft Store. You will get stuck trying to install dependencies later **</strong></p><p>Make sure to select the latest 64-bit version</p><figure class="kg-card kg-image-card"><img src="/assets/images/ghost/2020/04/Capture1.PNG" class="kg-image" alt loading="lazy"></figure><p>When installing also makes sure to adds python command to PATH</p><figure class="kg-card kg-image-card"><img src="/assets/images/ghost/2020/04/Capture2.PNG" class="kg-image" alt loading="lazy"></figure><p>Then uses <code>pip</code> to install <code>pipenv</code>. </p><pre><code class="language-bash">pip install --user pipenv</code></pre><p>Make sure to pay attention to the last few lines of output of the command complaining that what you installed is not on PATH. See and copy the highlighted value. If we somehow missed that message. Just uninstall by <code>pip uninstall pipenv</code> and try again.</p><figure class="kg-card kg-image-card"><img src="/assets/images/ghost/2020/04/Capture-1.PNG" class="kg-image" alt loading="lazy"></figure><p>Because of course this being Windows, it has to be hard. We need to set the PATH as instructed</p><ul><li>Click Start Menu -&gt; Type "environment" -&gt; Select "Edit Environment Variables for your Account"</li><li>Double-Click Path</li><li>Click Adds and paste in the path without the quotes e.g. <code>Users\varok\AppData\Local\Packages\Python<br>SoftwareFoundation.Python.3.8_qbz5n2kfra8p0\LocalCache\local-packages\Python38\Scripts</code>.</li><li>Click Okay and Okay again to close the windows</li><li>Close all terminal windows</li></ul><figure class="kg-card kg-image-card"><img src="/assets/images/ghost/2020/04/tempsnip.png" class="kg-image" alt loading="lazy"></figure><figure class="kg-card kg-image-card"><img src="/assets/images/ghost/2020/04/tempsnip2.png" class="kg-image" alt loading="lazy"></figure><p>Launch the terminal window again, Then type <code>pipenv</code> to see that the command is working</p><h2 id="how-to-use">How to use</h2><h3 id="create-a-new-project">Create a new project</h3><pre><code class="language-bash">$ pipenv --python 3</code></pre><h3 id="create-a-new-project-using-python-from-conda">Create a new project using python from Conda</h3><pre><code class="language-bash"># Or `where conda` for Windows

In addition it modifies two files, <code>Pipefile</code> and <code>Pipfile.lock</code>. One is used to describe the requirements as it is typed into the console. The other one records exactly what version of <code>requests</code> we pulled in when the above command ran. This helps in making sure the version of <code>requests</code> used by everybody in the team remains the same</p><p><strong>Pipfile </strong></p><pre><code>[packages]
requests = "*"

[requires]
python_version = "3.7"</code></pre><p><strong>Pipfile.lock</strong></p><pre><code>...

This is tremendously useful in project sharing scenario</p><h2 id="integrating-with-visual-studio-code">Integrating with Visual Studio Code</h2><p>Being awesome as usual, Visual Studio Code already detects the current <code>pipenv</code> virtual environment when opening the folder. </p><p>Provided that we already installed the Python extension to VSCode (see link below how).</p><figure class="kg-card kg-bookmark-card"><a class="kg-bookmark-container" href="https://code.visualstudio.com/docs/python/python-tutorial"><div class="kg-bookmark-content"><div class="kg-bookmark-title">Get Started Tutorial for Python in Visual Studio Code</div><div class="kg-bookmark-description">A Python hello world tutorial using the Python extension in Visual Studio Code (a great Python IDE like PyCharm, if not the best Python IDE)</div><div class="kg-bookmark-metadata"><img class="kg-bookmark-icon" src="https://code.visualstudio.com/favicon.ico" alt=""><span class="kg-bookmark-author">Visual Studio Code</span></div></div><div class="kg-bookmark-thumbnail"><img src="https://code.visualstudio.com/assets/docs/python/tutorial/social.png" alt=""></div></a></figure><p>All we need to do is casually checks that the environment reported matches. This is mostly transparent to us. However, if you change your project’s path, the mapping breaks and <code>pipenv</code> will no longer able to find the virtual environment</p><h2 id="references">References</h2><ul><li><a href="https://pipenv-fork.readthedocs.io/en/latest/">https://pipenv-fork.readthedocs.io/en/latest/</a></li><li><a href="https://github.com/LambdaSchool/CS-Wiki/wiki/Installing-Python-3-and-pipenv">https://github.com/LambdaSchool/CS-Wiki/wiki/Installing-Python-3-and-pipenv</a></li></ul>
