<p><a href="https://ghost.org/features/">Ghost</a> has advanced so much this year. At this point, I highly recommend it to everybody writing a technical blog. It is time to stop fiddling with Medium and jump over.</p><h3 id="advantages-over-medium">Advantages over Medium</h3><p>At least in these areas that matters to me</p><ul><li>HTML tag – Embed any JavaScript anywhere on the page. Very useful to show off any interactive coding or D3 snippet.</li><li>Beautiful Code Card – No more pasting code to Gist, then embed</li><li>Integrates with <a href="https://unsplash.com/">Unsplash</a> – Instant Beautiful Featured Image </li><li>No ads or nagging to log in or download native apps</li></ul><pre><code class="language-python">t = "your new blog!"
print( "Welcome to {}".format(t) )</code></pre><h3 id="advantages-over-wordpress">Advantages over Wordpress</h3><ul><li>Much faster than Wordpress for a simple blog</li><li>Excellent Medium-like interface while supporting much more customizations.</li><li>Very easy to install, and the default setup is production-ready with TLS</li><li>Integrates with Facebook, Twitter out of the box</li></ul><h3 id="install-ghost">Install Ghost</h3><p>Ghost bundled a very well though-out <a href="https://github.com/TryGhost/Ghost-CLI">CLI</a> for a smooth <a href="https://docs.ghost.org/install/ubuntu/">installation</a>. The easiest route, however, is to use the 1-click Digital Ocean installer.</p><p><a href="https://marketplace.digitalocean.com/apps/ghost">https://marketplace.digitalocean.com/apps/ghost</a></p><p>First time starting up the droplet, it will kick off the CLI to finalize installation. Just follow the prompt, which ask only two questions. Then everything is ready, including Nginx setup and SSL certificates via LetsEncrypt. Nice!</p><p>The whole secure-by-default process literally takes 10 minutes to setup. That is excellent.</p><p>If you prefer GCP, there's a click to deploy <a href="https://console.cloud.google.com/marketplace/details/click-to-deploy-images/ghost">here</a>.</p><h3 id="migrate-medium-posts-to-ghost">Migrate Medium Posts to Ghost</h3><p>Use this tool here. Follow the steps in README. All boils down to download the existing blog as a zip file from Medium, run the python script, upload the new zip file to Ghost.</p><p><a href="https://github.com/ageitgey/medium_to_ghost">https://github.com/ageitgey/medium_to_ghost</a></p><h3 id="customizations">Customizations</h3><p>Miscellaneous things  we could do right after set up</p><ol><li>Try some <a href="https://blog.ghost.org/language-code-cards/">code cards</a> with<a href="https://lookingsideways.co.uk/super-simple-code-highlighting-for-ghost/"> syntax highlight</a></li><li>Setup <a href="https://docs.ghost.org/integrations/google/">Google Analytics</a></li><li>Look at other <a href="https://docs.ghost.org/integrations/">Integrations</a></li><li>Setup CDN with CloudFlare – Make sure to use Strict, not Flex. The blog is already TLS enabled.  Using Flex will cause a redirect loop from http-&gt;https</li></ol><h3 id="oddities">Oddities</h3><ul><li>Imported featured image in Medium show up twice. Once in Featured Image and also as the first image of a post. </li><li>To Activate the code card. Type <code>```&lt;language&gt;</code> then press &lt;enter&gt;. Took me a while to realize that <code>enter</code> is important. </li><li>Despite an excellent code support, it does not come with syntax highlight. Although provide a great integration with <a href="https://prismjs.com/">prism.js</a> in particular. </li></ul>
